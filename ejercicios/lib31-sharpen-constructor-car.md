## ENUNCIADO

Un constructor te deja meterte EN EL MEDIO del paso de creación del
objeto, en el medio del `new`. ¿Se te ocurren situaciones en las que eso
sirva?

Imaginá una clase `Car` (auto) que es parte de un Racing Game (juego de
carreras de autos). De las acciones de abajo, ¿cuáles podrían servir
dentro del CONSTRUCTOR de `Car`? Tildá las que sirven y, para cada una
que tildes, escribí UN escenario concreto del juego donde la usarías
(eso es lo que pide el libro: "check off the ones that you came up with
a scenario for" = tildá aquellas para las que se te ocurrió un
escenario).

1. Increment a counter to track how many objects of this class type have
   been made. (Incrementar un contador para llevar la cuenta de cuántos
   objetos de esta clase se crearon.)
2. Assign runtime-specific state (data about what's happening NOW).
   (Asignar estado propio del momento de ejecución: datos sobre lo que
   está pasando AHORA.)
3. Assign values to the object's important instance variables. (Darles
   valor a las instance variables importantes del objeto.)
4. Get and save a reference to the object that's creating the new
   object. (Conseguir y guardar una referencia al objeto que está
   creando el objeto nuevo.)
5. Add the object to an ArrayList. (Agregar el objeto a un ArrayList.)
6. Create HAS-A objects. (Crear los objetos de una relación TIENE-UN.)
7. ________ (your idea here = tu idea acá): inventá una acción propia.
