(Head First Java, pág. 463-466 — Sesión #85 de la guía)

## POR QUÉ ESTÁ ADAPTADO

El libro cierra el capítulo con un crucigrama ("JavaCross"). Las
pistas originales son juegos de palabras EN INGLÉS: por ejemplo
"Or, in the courtroom" ("O, en el tribunal") funciona solo porque en
inglés la misma palabra nombra al colegio de abogados y al símbolo
`|`. Traducida, la pista deja de tener sentido; explicada, regala la
respuesta.

Así que se conserva lo que el ejercicio realmente entrena — repasar
el vocabulario del capítulo — en forma de definiciones directas.
**Las respuestas se escriben en inglés**, porque son los términos
reales de Java y los vas a necesitar en una entrevista.

## CÓMO SE RESUELVE

Escribí al lado de cada número la palabra Java que corresponde. Una
sola palabra por renglón (salvo donde se aclare). Sin mirar la guía
primero: probá de memoria, y recién después chequeá.

1. Tipo de dato que NO tiene comportamiento (no tiene métodos, no es
   un objeto). En Java hay 8 de estos.
2. El primitivo entero más usado de todos.
3. El primitivo entero más grande.
4. El segundo primitivo entero más chico (el más chico es `byte`).
5. El primitivo con decimales que Java usa POR DEFECTO cuando
   escribís `3.5`.
6. El otro primitivo con decimales, el de menos precisión.
7. El primitivo que solo puede valer `true` o `false`.
8. Lo que se puede sobrescribir en una clase; es donde vive el
   comportamiento.
9. Cada cosa guardada adentro de un `ArrayList`, que se puede pedir
   por su posición.
10. La palabra para "posición" dentro de una lista o un arreglo.
11. La clase de `java.util` que el libro describe como "un arreglo
    con esteroides": crece sola, no tiene tamaño fijo.
12. El método de `ArrayList` que lo hace crecer.
13. El método de `ArrayList` que dice cuántos elementos tiene ahora.
14. Lo que se usa en un ARREGLO común para saber cuántas posiciones
    tiene (ojo: no es un método, no lleva paréntesis).
15. El método de `ArrayList` que contesta si está vacío.
16. La línea del principio del archivo que te evita escribir el
    nombre completo de una clase todo el tiempo.
17. La lista de lugares donde Java sale a buscar los paquetes al
    compilar y al ejecutar.
18. La sigla con que se conoce a la biblioteca de Java y a su
    documentación.
19. Estructura de código que hace que algo se repita.
20. Cómo pasa Java los argumentos a un método: no manda el original,
    manda una ___ del valor. (Dos palabras.)
