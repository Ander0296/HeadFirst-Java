Cerramos esta sesión para arrancar una limpia. Sin resumen largo:

1. Confirmá en UNA línea que la tanda quedó registrada: `GUIA-JAVA.md`
   (sesión + vocabulario + INICIO RÁPIDO), `MECANOGRAFIA.md` + su
   archivo de ttyper, `ANKI.txt`, y que todo ejercicio nuevo tiene su
   archivo de arranque creado.
2. Actualizá la línea **PRÓXIMA SESIÓN** del INICIO RÁPIDO de
   `GUIA-JAVA.md` con el nombre de la sesión que viene. Si no la
   actualizás, esta sesión no está cerrada.
3. Guardá en Engram la última página vista y qué sigue.
4. Corré el chequeo de seguridad de git (REGLA DE GIT de CLAUDE.md),
   mostrame qué cambió y con qué mensaje de commit, y pedime el OK.
   Con el OK: `git add` + `git commit` + `git push`.
5. Cerrá con el bloque `▶ SIGUE`, con el `Ctrl+D`, el `/rename` de la
   próxima sesión y el comando con el que arranca, y en una línea con
   qué seguimos.
